# Sistemas Operativos I - Clase 1

Proyecto preparado para heredar la misma plantilla editorial utilizada por el libro de Algoritmos.

## Instalación

1. Copie la carpeta `sistemas-operativos-I` dentro de `books/`.
2. Verifique que existan las rutas compartidas:
   - `editorial/scss/editorial.scss`
   - `editorial/templates/header.tex`
3. Abra el proyecto desde la carpeta `books/sistemas-operativos-I`.
4. Ejecute en la terminal:

```bash
quarto render
```

## Salidas

Los archivos se generarán en:

- `_site/index.html`
- `_site/Sistemas-Operativos-I.pdf` o el nombre definido por Quarto.
